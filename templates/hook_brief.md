# Hook 决策模板

> 用途：歌词动笔前最后一步——先把抓手钉死，再写 verse。
> 输入：`research.md` + `key_points.md` + `mood.md` + `brief.md` 已完成
> 产出：`songs/<主题>/hook.md`
> 硬规则：**Duoqi 没确认 hook 之前不要进歌词**。hook 不够打动人，verse 再好也救不回来。

---

## Part A：概念 hook（整首立意角度）

### A1. 视角创意（选 0 或 1）

- [ ] 不寻常视角：__________（如：妈妈写给孩子 / 孩子写给亡父 / 未来的我写现在 / 物件视角）
- [ ] 写信体：「亲爱的 ___」贯穿全篇
- [ ] 对话体：在跟某人说话，对方不回应
- [ ] 默认（不选）：第一人称直叙

### A2. 隐喻锚点（强烈推荐选 1）

找一个**具体的物 / 场景**贯穿全篇，所有 verse 围绕它展开。

| 类型 | 例子 |
|---|---|
| 物件 | 一封信、一双鞋、一张照片、一把伞、一盏灯、一条围巾 |
| 场景 | 夜里的厨房、医院走廊、回家的路、儿童房门口、老家厨房 |
| 自然 | 一棵树、一朵云、一场雨、一片海、一阵风 |
| 身体 | 一双手、白头发、皱纹、心跳、呼吸 |

我选的锚点：__________

> 为什么需要锚点：避免歌词飘在抽象情绪里。听众需要视觉记忆点，"那个物件"会变成歌的代名词。

### A3. 反差 / 张力（加分项，可选）

- [ ] 喜剧外壳 + 悲剧内核（轻快旋律唱沉重事）
- [ ] 温柔语气 + 残酷内容
- [ ] 平静叙事 + 突然爆发的一句
- [ ] 第三人称写自己（拉开距离）

---

## Part B：副歌 hook（那一句"歌名级"的话）

### B1. 长度

- [ ] 短（3-5 字）：洗脑王（"对不起" / "我想你"）
- [ ] 中（6-9 字）：主流（一句完整有情绪的呼告或陈述）
- [ ] 长（10 字+）：需旋律线极强，慎用

### B2. 句式

- [ ] 陈述："我们都一样"
- [ ] 问句："你还记得吗 / 还要走多远"
- [ ] 呼告："妈妈，妈妈" / 直接喊名字
- [ ] 比喻："你是我心上的一颗星"
- [ ] 命令："别回头" / "走吧"

### B3. 必含元素（至少 1 项）

- [ ] 歌名词（让 hook 包含歌名，听完能记住歌叫啥）
- [ ] A2 锚点的关键意象词（让概念 hook 和副歌 hook 呼应）
- [ ] 情感动词（爱 / 恨 / 想 / 忘 / 走 / 留 / 等 / 归 / 长大）
- [ ] 具体称呼（"你" / "妈妈" / 名字）

### B4. 重复递进策略（决定 C1 / C2 / C3 怎么变）

| 策略 | 例子（示意） |
|---|---|
| 完全重复 | C1 = C2 = C3，靠旋律和编曲递进 |
| 一字之差（推荐） | "我等你回来" → "我等你回头" → "我等不到你" |
| 同骨架换名词 | "你是我的春天" → "你是我的黄昏" → "你是我的灯火" |
| 末尾递进 | C1 收"还在等" → C2"已不等" → C3"等到了" |

> 这条同时是 CLAUDE.md「歌词结构硬要求」的具体落地——hook 重复递进自然就把 chorus 句式骨架定下了。

## Part C：自检清单（写完 hook 后跑一遍）

- [ ] 副歌 hook 能不能脱离整首歌单独被记住？（口头哼一遍试试）
- [ ] hook 念出来上口吗？拍手数音节，有没有卡住的地方？
- [ ] hook 里有没有多音字 / 拗口字？（按 CLAUDE.md 多音字硬要求扫一遍）
- [ ] hook 跟概念 hook（A 部分）能不能呼应？比如锚点物件出现在副歌里？
- [ ] 只听到 hook 一句的人，能不能猜到这首歌的情绪？
