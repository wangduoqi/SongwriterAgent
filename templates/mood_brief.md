# 基调决策模板

> 用途：歌词动笔前的第一步对齐，定整首歌的情绪坐标。
> 输入：`songs/<主题>/research.md` + `key_points.md`（如果是内容创作题材）；个人情感题材可以跳过这两个直接做 mood
> 产出：`songs/<主题>/mood.md`

---

## 五个维度，逐条对话决策

### 1. 情绪主色（必选 1，可选 1 副）

挑主色：

- [ ] 悲伤 / 哀悼 / 失去
- [ ] 反思 / 释怀 / 顿悟
- [ ] 温暖 / 治愈 / 守护
- [ ] 愤怒 / 控诉 / 不甘
- [ ] 戏谑 / 反讽 / 自嘲
- [ ] 浪漫 / 思念 / 暧昧
- [ ] 孤独 / 疏离
- [ ] 希望 / 重启 / 向前
- [ ] 怀旧 / 缅怀

副色（可留空）：__________

> 主+副组合很关键。"温暖+悲伤"和"愤怒+悲伤"是完全不同的歌。

---

### 2. 能量曲线（决定编曲爆点）

- [ ] **静默型**：全程压低，自语，几乎没有副歌爆发（folk / R&B 慢板）
- [ ] **后置爆发**：V 静、C1 微起、C2 / Bridge 才放（最常用，慢板首选）
- [ ] **早爆发**：Hook 前置或 C1 即顶点（Trap / 流行摇滚）
- [ ] **全程高能**：罕见，仅 rock anthem / 派对歌
- [ ] **波浪型**：起-收-起-收（双 Bridge / 长歌）

---

### 3. 视角与人称

| 选项 | 距离感 | 适合 |
|---|---|---|
| 第一人称"我" | 最近 | 自传、情感直叙 |
| 第二人称"你" | 私密对话 | 写给具体一个人（孩子 / 爱人 / 亡者） |
| 第三人称"他/她" | 旁观冷静 | 历史人物、群像 |
| 全知视角 | 上帝俯瞰 | 历史事件、宏大叙事 |
| 物件视角 | 隐喻 | 一封信 / 一棵树替主角发声 |

我选：__________

---

### 4. 时间立足点

- [ ] 进行中（"今晚 / 现在"）
- [ ] 事后回望（"那一年 / 后来"）
- [ ] 双线交织（童年 vs 现在 / 生前 vs 死后）
- [ ] 虚拟语气（"如果当时…"）
- [ ] 脱离时间（哲理 / 意象，无时态）

---

### 5. 听完想留下什么 — **最重要的一条**

一句话填空："我希望听完的人 ______"

例：
- "心里酸一下，想给爸妈打个电话"
- "沉默 5 秒"
- "跟着哼副歌"
- "想起某个具体的人"
- "决定明天去做某件事"

填：__________

> 这一条决定了所有其他决策的取舍方向。先答这条，其他四条围绕它对齐。

---

## 写入 `mood.md` 的最终记录

```markdown
# <主题> · 基调

- 情绪主色：<主> + <副>
- 能量曲线：<选项>
- 视角人称：<选项>
- 时间立足点：<选项>
- 听完想留下：<一句话>
- 决策时间：<YYYY-MM-DD>
```
