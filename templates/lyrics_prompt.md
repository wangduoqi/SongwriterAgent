# 歌词创作模板

> 用途：写 `vN_lyrics.txt` 时的结构和硬约束。
> 输入：`research.md` + `key_points.md` + `brief.md` 都已完成。
> 输出：**至少 2 个版本**的完整歌词，每版存一个文件。

---

## 一、输入检查清单（动笔前确认）

- [ ] 读完了 `songs/<主题>/research.md`
- [ ] 读完了 `songs/<主题>/key_points.md`（知道核心冲突、意象、hook 候选）
- [ ] 读完了 `songs/<主题>/brief.md`（知道歌词类型、结构、押韵要求）
- [ ] 知道这版用哪 1-2 个歌词型（叙事 / 抒情 / 哲理 / 意象 / 态度 / 功能）

缺任何一项 → 停下来找 Duoqi 补。

---

## 二、Suno 结构标记（必须用英文方括号）

Suno 靠这些标签断段，不能写错：

```
[Intro]
[Verse]   或   [Verse 1] [Verse 2]
[Pre-Chorus]
[Chorus]
[Post-Chorus]
[Bridge]
[Outro]
```

可选标记（Suno 支持）：
```
[Instrumental]
[Guitar Solo]
[Spoken]
```

---

## 三、输出格式（`vN_lyrics.txt` 样例）

```
[Verse 1]
<4 行，每行 7-12 字>

[Pre-Chorus]
<2 行，情绪铺垫>

[Chorus]
<4 行，hook 必须出现；每段 chorus 一字不差重复，除非故意变奏>

[Verse 2]
<4 行，推进情节 / 换视角 / 加细节>

[Pre-Chorus]
<同上或微调>

[Chorus]
<同上>

[Bridge]
<4 行，情绪翻转或抽象升华；避免和 chorus 押同韵>

[Chorus]
<同上，可在最后一句升 key 或加修饰>
```

---

## 四、硬约束（违反就重写）

### 押韵
- 每段内部至少 AABB 或 ABAB
- Chorus 末字韵脚要稳，通篇统一（除非 bridge 故意换）
- 中文押韵按**普通话韵母**，不是字形

### 口语化
- 每一句都要**能自然念出来**，不拗口
- 禁用倒装强行押韵（"心碎的我在夜里"而不是"在夜里我心碎")
- 禁用 AI 套话高发词：岁月 / 流年 / 时光的河 / 命运的齿轮 / 心似 / 如歌 / 奈何 / 红尘

### 具象 > 抽象
- 每段至少 1 个来自 `research.md` 的具体锚点（地名 / 物件 / 数字 / 动作）
- 情感要通过具象表达，不能直接说"好悲伤""我爱你"

### 信息密度（按型调整）
- 功能型 / 叙事型：每句都有信息，别空转
- 抒情型 / 意象型：可以留白，但不能灌水

### 字数
- Verse 行长 7-12 字为宜
- Chorus 行长 6-10 字为宜（要朗朗上口）
- 同一段内行长差别不要过大（节奏感）

---

## 五、多版本差异化策略

**至少产出 2 版**，差异点必须明确，不能只是同义词替换。推荐差异维度：

| 维度 | v1 vs v2 例子 |
|---|---|
| 歌词型 | 叙事 vs 意象 |
| 视角 | 旁观者 vs 当事人第一人称 |
| 时态 / 时间点 | 事件当下 vs 多年以后回望 |
| 态度 | 同情 vs 反讽 |
| Hook 方向 | 疑问句 hook vs 断言 hook |

每版**写完后在文件末尾加一个注释块**（不影响 Suno，Suno 会忽略 `# ` 开头的行吗？—— 不会忽略。所以注释单独存 `songs/<主题>/notes.md`，不要混进 `_lyrics.txt`）。

---

## 六、交付清单（写完后检查）

- [ ] 两个版本的 `vN_lyrics.txt` 已生成
- [ ] 每版有完整结构标记
- [ ] 押韵扫一遍（念一遍末字）
- [ ] 口语化扫一遍（自己小声念，卡壳就改）
- [ ] AI 套话词扫一遍（搜禁用词列表）
- [ ] `notes.md` 追加：v1 走了什么型、v2 走了什么型、差异点、我哪里还不确定

交给 Duoqi 挑，等他选版或给反馈 → 定稿后才走 Suno 提交。

---

## 七、反馈后修订（v3+）

Duoqi 给反馈后，不要大改，按他指的地方改：

- 他说"副歌第二句太虚" → 只改那一句，其他不动
- 他说"v2 副歌好、主歌换 v1 的" → 合并出 v3
- **永远新建文件**，不覆盖旧版

修订同步更新 `notes.md`：记"v3 = v1 主歌 + v2 副歌，修订副歌第 2 行"。
