## 一、风格友好度

### 强项（首选，几乎不出错）

| 风格 | 推荐 BPM | 备注 |
|---|---|---|
| **Mandopop 抒情慢板** | 70-85 | 中文情歌钢琴+弦乐+真声拔高，4.5 后非常自然 |
| **Folk / Country** | 80-110 | 木吉他叙事，几乎不出错 |
| **Pop / Pop Rock** | 100-130 | 标准 V-PC-C 结构 AI 速选区 |
| **City Pop / Synthwave** | 100-115 | 复古质感本就是 AI 优势 |
| **Indie / Bedroom Pop** | 80-110 | 低预算质感 AI 强项 |
| **EDM / Dance Pop** | 120-140 | 数学精密，AI 比人稳 |
| **Lo-fi / Chillhop** | 70-95 | 循环为基础，AI 源源不断 |
| **R&B / Soul** | 70-95 | 4.5 后中等偏强，转音能做 |
| **古风 Fusion** | 70-100 | 古筝+笛子+现代制作 4.5 后到位 |
| **轻摇滚 / Soft Rock** | 90-115 | 木吉他+电吉他点缀，稳 |

### 中等（可做，但需要多次重抽 / 部分细节不可控）

| 风格 | 备注 |
|---|---|
| Metal / Hard Rock | 失真吉他、双 kick OK；blast beats 不稳 |
| Pop Punk / Emo Revival | 年代感复刻好，主唱情绪还行 |
| Trap / Hip-hop | 808 鼓和 auto-tune flow 稳；密集 hi-hat 偶尔糊 |
| Reggae / Dub | 节拍能学到，但律动 swing 不够 |
| Smooth Jazz / Vocal Standard | 标准型可以，复杂和声仍弱 |
| K-pop / J-pop 风格化 | 整体能学到，唱腔细节差异化弱 |

### 弱项（避免，或仅用作背景 / 实验）

| 风格 | 原因 |
|---|---|
| **古典交响乐** | 长结构、严密情感逻辑，AI 缺整体观 |
| **爵士 bebop / fusion** | 即兴、不规则切分音是核心，AI 模拟不出灵魂 |
| **Hardcore Metal / Math Rock** | 极复杂节拍变化、blast beats |
| **Acoustic 纯人声 a cappella** | 没编曲遮瑕，电音感无处遁形 |
| **传统戏曲（京剧/越剧/粤剧）** | 训练数据少，唱腔特殊 |

## 二、节奏 / BPM 友好度

| BPM | 适合 | Suno 表现 |
|---|---|---|
| **<50** | 极慢 ambient | 弱，长音颤 |
| 50-69 | 极慢 ballad | 中等，长音偶有颤 |
| **70-89** | **中文抒情慢板 / R&B** | **强（最佳之一）** |
| 90-109 | 民谣 / 轻摇滚 | 强 |
| **110-129** | **流行 / Pop Rock / City Pop** | **强（最佳之一）** |
| 130-149 | Dance Pop / EDM | 强 |
| 150-170 | 快速 EDM / hardstyle | 中等 |
| **>170** | Trap (hi-hat 密集) / Metal | 弱 |

**永远的硬伤（不论版本）**：

- **Rubato（自由速度变化）**：AI 不会处理。需要"突然慢下来再爆发"或"刻意延迟一拍"的情绪表达，AI 永远做不出
- **极端切分 / 拍子变化**（5/4、7/8、复合拍）：AI 默认 4/4，强行写多拍号容易乱

## 三、其他维度

### 3.1 语言

| 语言 | 友好度 |
|---|---|
| 英文 | 强（训练数据最多） |
| 中文普通话 | 强（4.5+），需多音字消歧（见 CLAUDE.md） |
| 日语 / 韩语 | 中（K-pop 风格化时不错） |
| **粤语** | **弱**（发音不准，是重要弱项） |
| 闽南语 / 台语 | 弱 |
| 中英混搭 | 中（少量 OK，过多会乱） |

### 3.2 人声

| 类型 | 友好度 |
|---|---|
| 女声真声拔高（Mandopop diva） | 强 |
| 男声中低音 | 强 |
| 男声高音 / 假声 | 中（偶尔破音） |
| 童声 | 弱（听感假） |
| 老人声 / 沙哑磁性 | 中 |
| 多人合唱 / 和声层 | 中 |
| **Duet 男女对唱轮换** | **弱**，需明确标记，效果不稳 |

### 3.3 长度

- **≤4 分钟最稳**（Suno 单次生成限制）
- 4-6 分钟靠 extend，结构容易跑偏
- **<2 分钟反而难**——AI 不会自动做减法，结构会被压扁
- **默认目标：~3 分钟**（CLAUDE.md 已有规则）

### 3.4 编曲复杂度

- 简单（1-2 件主乐器+人声）：最干净
- 中等（典型 band，3-4 件乐器）：稳
- 复杂（>5 件乐器堆叠）：mix 容易糊，人声被埋

> **实战法则**：style_prompt 写 **2-4 个核心乐器** 比写 7-8 个效果更好。

### 3.5 情感戏剧性

| 转折次数 | 表现 |
|---|---|
| 单调情感（平 / 一路爬） | 稳 |
| 一次转折（V 静 → C 爆） | 强项 |
| 两次转折（V→C→Bridge 冷→大 C 重爆） | 4 分钟极限 |
| 三次以上 | AI 不一定听话，需多次重抽 |

### 3.6 特殊技巧

| 技巧 | 友好度 |
|---|---|
| `[Spoken]` 念白 | 中（能做但语感生硬） |
| Ad-lib（"yeah ohh"那类） | 中（4.5 后可触发，靠 `[ad-libs]` 标记） |
| Scat 拟声 | 弱 |
| 颤音 / 转音 | 中-强（4.5 改善大） |
| 气声 / 耳语 | 中（需写 `whispered vocal`） |
| Beatbox / 拟声打击 | 弱 |
| 哼唱段落 | 中（`[Humming]` 标记可触发） |

### 3.7 风格融合（跨流派）

- 单一明确流派：稳
- 两流派融合（"trap meets folk"）：中（需多次重抽）
- 三流派以上堆叠：弱（基本糊）
