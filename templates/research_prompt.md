# 素材调研模板

> 用途：写**内容创作类歌曲**（历史、时事、剧情、人物）前的第一步。
> 流程：Claude 按清单问我要资料 → 我粘贴 → Claude 整理成 `research.md`。

---

## 一、先确定题材类型

勾选一个（决定下面要问哪些资料）：

- [ ] 历史事件
- [ ] 时事热点
- [ ] 电视剧 / 电影 / 动漫剧情
- [ ] 人物（传记 / 名人 / 虚构角色）
- [ ] 社会现象 / 文化议题
- [ ] 其他：__________

---

## 二、Claude 向我要资料的清单（按题材勾选）

### 通用（所有题材）
- [ ] 一句话概括：这事 / 这人 / 这剧 是关于什么的
- [ ] 我为什么想写这个（情感动机 / 想表达的立场）
- [ ] 想给谁听（目标听众，影响语言风格）

### 历史 / 时事类
- [ ] **时间线**：关键节点按时间顺序
- [ ] **关键人物**：每个角色一句话定位
- [ ] **核心冲突**：对立双方 / 矛盾是什么
- [ ] **公众反应 / 影响**：当时和后来
- [ ] **细节锚点**：具体的数字、地点、物件、台词（歌词需要具象）
- [ ] **有争议的部分**：不同视角的说法

### 剧情类（剧 / 电影 / 动漫）
- [ ] **背景设定**：世界观一句话
- [ ] **主角及动机**：他要什么、怕什么
- [ ] **剧情主线**：按集 / 幕推进
- [ ] **关键转折**：3-5 个
- [ ] **标志性画面 / 台词**
- [ ] **主题**：作品想表达什么
- [ ] **剧透尺度**：能不能写结局？

### 人物类
- [ ] **生平骨架**：出生 / 成名 / 转折 / 结局
- [ ] **代表作 / 代表事件**
- [ ] **标签与反标签**：大众怎么看他，真实是否不同
- [ ] **亲口说过的话 / 经典语录**
- [ ] **想突出哪一面**（不可能面面俱到）

## 四、Claude 的整理输出（写入 `songs/<主题>/research.md`）

格式：

```markdown
# <主题> · 素材整理

## 一句话
<一句话概括>

## 时间线 / 情节骨架
- <时间或节点>：<发生了什么>
- ...

## 关键人物 / 角色
- **<名字>**：<定位、动机、结局>

## 核心冲突
<对立的是什么 vs 什么>

## 可入词的具象锚点
- <具体画面 / 物件 / 数字 / 地点>（来源：资料 N）
- ...

## 情感基调候选
<悲悯 / 讽刺 / 敬意 / 惋惜 / 愤怒 / ...>

## 原文引用（供核对）
> "<原文句子>" —— 资料 N
```

**硬要求**：每个事实在整理稿里都要能对应回原始资料段落。Claude 不许自己补料。
